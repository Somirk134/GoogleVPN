【第一步】双击运行 "一键安装.bat"

  这个脚本会帮你:
  ✓ 从你的 vpn.png 生成所需的图标
  ✓ 配置 Go 代理（使用国内镜像，不会乱码）
  ✓ 下载所有依赖
  ✓ 启动 Agent 服务

【第二步】在脚本菜单中选择 [4] 完整安装

  等待安装完成...

【第三步】选择 [3] 启动 Agent 服务

  看到这个就成功了:
  "Application started successfully"
  
  ⚠️ 保持这个窗口运行，不要关闭！

【第四步】在 Chrome 中加载扩展

  1. 打开 Chrome 浏览器
  2. 地址栏输入: chrome://extensions/
  3. 开启右上角的"开发者模式"开关
  4. 点击"加载已解压的扩展程序"
  5. 选择项目中的 extension 文件夹
  6. 完成！

【第五步】测试

  点击浏览器工具栏的扩展图标
  应该能看到 Proxy Manager 的界面！

【如果遇到问题】

问题 1: Python 未安装
解决: 
  - 方案 A: 安装 Python (https://www.python.org/downloads/)
  - 方案 B: 使用在线工具生成图标
  - 方案 C: 手动创建 4 个 PNG 文件

问题 2: Go 依赖下载失败
解决: 脚本会自动尝试多个镜像源，耐心等待

问题 3: Agent 启动失败
解决: 
  - 检查端口 8765 是否被占用
  - 查看 logs\agent.log 日志文件

问题 4: Extension 无法加载
解决: 确保 extension\icons\ 目录下有图标文件
