新手引导

一步步教你完成配置

1安装 Clash
2找到外部控制
3填写配置
4完成

第一步：安装 Clash Verge

Proxy Manager 需要配合 Clash 客户端使用。推荐使用 Clash Verge Rev。

1 下载并安装 Clash Verge Rev
2 打开 Clash Verge，导入你的订阅链接
3 确保 Clash Verge 正在运行（系统托盘有图标）
如果你已经安装好了 Clash Verge 并导入了订阅，直接点下一步

第二步：找到外部控制地址和密钥

打开 Clash Verge，按以下步骤操作：

1
打开 Clash Verge 设置
点击左侧菜单的「设置」（齿轮图标）
2
找到「Clash 外部控制」
在设置页面中找到「外部控制」一栏，你会看到类似这样的内容：
外部控制 127.0.0.1:9097
密钥 (Secret) set-your-secret
3
记下这两个值
把「外部控制」的地址和「密钥」记下来，下一步要用
不同版本的 Clash Verge 界面可能略有不同，但「外部控制」一般都在设置页面

第三步：填写配置

把上一步获取的信息填到下面：

格式：http://127.0.0.1:端口号（端口号就是外部控制里冒号后面的数字）
如果 Clash Verge 没有设置密钥，留空即可

配置完成

现在你可以关闭这个页面，点击浏览器右上角的 Proxy Manager 图标开始使用了。

如果之后需要修改配置，可以在「连接设置」中修改
