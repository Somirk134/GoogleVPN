# 图标文件说明

请准备以下尺寸的图标文件：

- icon16.png (16x16)
- icon32.png (32x32)
- icon48.png (48x48)
- icon128.png (128x128)

## 图标设计建议

- 使用简洁的代理/网络相关图标
- 背景透明
- 使用蓝色或绿色主题色
- 确保在浅色和深色背景下都清晰可见

## 临时方案

在开发阶段，你可以：
1. 使用在线图标生成工具创建简单图标
2. 或者从 https://www.flaticon.com/ 下载免费图标
3. 使用图片编辑工具调整到所需尺寸

## 图标内容建议

可以使用以下元素：
- 地球仪 + 箭头
- 网络节点图标
- 代理服务器图标
- 简单的字母 "P" (Proxy)
