  如果 Pillow 安装很慢 - 快速解决方案
═══════════════════════════════════════════════════════════

【方案 1: 使用快速安装脚本（推荐）】

1. 按 Ctrl+C 停止当前安装
2. 运行: scripts\install_pillow.bat
3. 这个脚本会自动使用国内镜像（清华/阿里云/豆瓣）

【方案 2: 手动使用国内镜像】

按 Ctrl+C 停止，然后运行：

pip install -i https://pypi.tuna.tsinghua.edu.cn/simple Pillow

或者：

pip install -i https://mirrors.aliyun.com/pypi/simple/ Pillow

【方案 3: 跳过 Pillow，手动准备图标】

如果实在安装不上，可以跳过图标生成：

1. 按 Ctrl+C 停止安装
2. 使用在线工具生成图标:
   https://www.favicon-generator.org/
   
3. 或者手动创建 4 个 PNG 文件:
   - 用画图工具打开你的 vpn.png
   - 调整大小为 16x16, 32x32, 48x48, 128x128
   - 分别保存为 icon16.png, icon32.png, icon48.png, icon128.png
   - 放到 extension\icons\ 目录

4. 然后继续运行一键安装的其他步骤

【方案 4: 永久配置 pip 使用国内镜像】

创建或编辑文件: C:\Users\你的用户名\pip\pip.ini

内容:
[global]
index-url = https://pypi.tuna.tsinghua.edu.cn/simple
[install]
trusted-host = pypi.tuna.tsinghua.edu.cn

然后重新运行: pip install Pillow
