【快速开始 - 3 步搞定】

1. 双击运行 "一键安装.bat"
   - 选择 [4] 完整安装
   - 等待安装完成

2. 选择 [3] 启动 Agent 服务
   - 看到 "Application started successfully" 表示成功
   - 保持窗口运行，不要关闭

3. 在 Chrome 中加载扩展:
   - 打开 chrome://extensions/
   - 开启右上角"开发者模式"
   - 点击"加载已解压的扩展程序"
   - 选择项目中的 extension 文件夹
   - 完成！

【常见问题】

Q1: 图标生成失败？
A: 需要安装 Python 和 Pillow 库
   方法 1: pip install Pillow
   方法 2: 使用在线工具 https://www.favicon-generator.org/
   方法 3: 手动创建 4 个 PNG 文件 (16x16, 32x32, 48x48, 128x128)

Q2: Go 依赖下载失败？
A: 脚本会自动配置国内镜像
   如果还是失败，检查网络连接

Q3: Agent 启动失败？
A: 检查以下几点:
   - 端口 8765 是否被占用
   - Go 依赖是否安装完成
   - 查看 logs\agent.log 日志

Q4: Extension 无法加载？
A: 确保 extension\icons\ 目录下有图标文件

Q5: Popup 显示"未连接"？
A: 确保 Agent 服务正在运行
